KATHANABOT BUFF WATCH ICON LIBRARY

Drop PNG, BMP, JPG, or JPEG buff-icon images directly into this folder.

The starter library is embedded inside the standalone EXE. If this folder is missing, the bot
creates it beside the EXE and extracts all missing starter icons automatically on first launch.

- The image filename becomes the icon name shown in Buff Watch.
- Example: Divine_Shield.png appears as "Divine_Shield".
- Open Buff Watch > Add From Library... and press Refresh after adding files.
- Optional subfolders become categories in the icon selector.
- Keep this folder beside the standalone KathanaBotControlPanel EXE when moving it.
- The existing Capture from Game and Import from File options remain available.
