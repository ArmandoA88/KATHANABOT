# KathanaBot 1.0.96

## What changed

- **New: Buff Watch.** Define a shared "Buff Area" (calibrated the same way as HP/MP bars) and a library of buff icons (captured from the game or imported from a file, organized into categories); when a watched buff's icon is no longer found anywhere in the area, its recast key is sent automatically. Includes an adjustable icon capture size with a zoomed confirm-before-save preview, and an optional self-click point for buffs that require selecting yourself first.
- **Hold to Show Game Window is now reliable across monitors and other apps.** Holding the assigned hotkey (default F10) brings the game window to the front; releasing it reliably returns focus to whatever was active before, regardless of which monitor or application had focus.
